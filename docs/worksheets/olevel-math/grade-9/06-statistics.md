### 📘 Topic Concept

**Types of Data**
- *Discrete*: counted (e.g. number of children).
- *Continuous*: measured (e.g. height, mass).

**Averages**
- **Mean**: $\bar{x}=\dfrac{\sum x}{n}$ (sum of values ÷ number of values).
- **Median**: the middle value when data is arranged in order. For $n$ values:
  - if $n$ is odd → median $=\left(\dfrac{n+1}{2}\right)$th value;
  - if $n$ is even → median $=$ mean of $\dfrac{n}{2}$th and $\dfrac{n+2}{2}$th values.
- **Mode**: the most frequently occurring value (or *modal class* for grouped data).

**Range** $=$ largest value $-$ smallest value.

**Frequency Tables**
For grouped data, mean $=\dfrac{\sum fx}{\sum f}$, where $x$ is the value (or class midpoint) and $f$ is its frequency.

**Charts & Graphs**
- *Bar chart*: equal-width bars, gaps between bars (categorical data).
- *Pie chart*: angle of each sector $=\dfrac{\text{frequency}}{\text{total}}\times 360^{\circ}$.
- *Pictogram*: each picture stands for an agreed quantity.

### ✅ Answer Key

**Q1.** Sorted: $14,15,15,15,17,18,18,19,20,22,25$.
**(a)** Mean $=\dfrac{15+18+22+19+15+25+14+15+20+17+18}{11}=\dfrac{198}{11}=\boxed{18}$.
**(b)** Median ($6$th value) $=\boxed{18}$.
**(c)** Mode (most frequent) $=\boxed{15}$.
**(d)** Range $=25-14=\boxed{11}$.

---

**Q2.** Sum of $5$ numbers $=5\times 14=70$. Sum of given four $=10+12+15+18=55$. Fifth number $=70-55=\boxed{15}$.

---

**Q3.**
**(a)** Highest frequency is $9$ → mode $=\boxed{1}$ pet.
**(b)** $30$ values → median is mean of $15$th and $16$th values. Cumulative: $0$ → 6, $1$ → 15, $2$ → 23. Both $15$th and $16$th lie in different classes ($15$th is "$1$ pet", $16$th is "$2$ pets"). Median $=\dfrac{1+2}{2}=\boxed{1.5}$.
**(c)** $\sum fx=0(6)+1(9)+2(8)+3(5)+4(2)=0+9+16+15+8=48$. Mean $=\dfrac{48}{30}=\boxed{1.60}$ pets.

---

**Q4.** Each $1^{\circ}=\dfrac{360}{360}=1$ student. So:

$$\text{Bus}=144,\;\text{Walk}=108,\;\text{Cycle}=72,\;\text{Car}=36$$

$$\boxed{144,\;108,\;72,\;36}$$

(check: $144+108+72+36=360$ ✓)

**Q5.** Old total $=4\times 48=192$. New total $=192+73=265$. New mean $=\dfrac{265}{5}=\boxed{53\;\text{mm}}$.

**Q6.**
**(a)** Highest frequency is $20$ → modal class $=\boxed{400\le t<600}$.
**(b)** Use class midpoints $100,\;300,\;500,\;700,\;900$:

$$\sum fx=4(100)+11(300)+20(500)+17(700)+8(900)=400+3300+10000+11900+7200=32800$$

$$\text{Mean}=\dfrac{32800}{60}\approx\boxed{547\;\text{h}}\;(3\;\text{s.f.})$$

**Q7.**
**(a)** $\sum fx=1(7)+2(9)+3(8)+4(10)+5(6)+6(8)=7+18+24+40+30+48=167$.

$$\text{Mean}=\dfrac{167}{48}\approx\boxed{3.48}\;(2\;\text{d.p.})$$

**(b)** $3.48$ is very close to the theoretical $3.5$, so **yes**, the result is consistent with a fair die.

**(c)** Highest frequency $15$ → mode $=\boxed{C}$.

**Q9.** Old total $=9\times 20=180$. New total $=10\times 22=220$. So $k=220-180=\boxed{40}$.

**Q10.**
**(a)** Test 1 sum: $32+38+41+28+45+40+36+33+47+42+39+30+44+37+31+46+35+43+29+34=750$.
Mean Test 1 $=750/20=\boxed{37.5}$.

Test 2 sum: $30+42+39+25+47+38+33+31+48+40+36+28+45+34+29+46+32+41+27+30=721$.
Mean Test 2 $=721/20=\boxed{36.05}$.

**(b)** The class performed better on **Test 1** because its mean ($37.5$) is higher than Test 2's mean ($36.05$).

**(c)** Range Test 1 $=47-28=\boxed{19}$. Range Test 2 $=48-25=\boxed{23}$.

**(d)** Test 1 was more consistent: a smaller range ($19$ vs $23$) indicates the marks were closer together, so performance was more uniform.
