### 📘 Topic Concept

The **derivative** of a function $y=f(x)$ is denoted $\dfrac{dy}{dx}$ or $f'(x)$ and gives the **gradient** of the curve at a point — equivalently the **rate of change** of $y$ with respect to $x$.

**Power Rule**

$$\frac{d}{dx}\left(x^{n}\right)=nx^{n-1}\quad\text{for any constant }n\neq 0$$

**Constant rule** — $\dfrac{d}{dx}(c)=0$.

**Sum rule** — $\dfrac{d}{dx}(f+g)=f'+g'$.

**Constant multiple** — $\dfrac{d}{dx}(kf)=kf'$.

**Tangent and Normal at $x=a$**
- Tangent: $y-f(a)=f'(a)(x-a)$.
- Normal: gradient $=-\dfrac{1}{f'(a)}$ (perpendicular to tangent).

**Stationary Points** — where $f'(x)=0$.
**Second Derivative** $f''(x)$ classifies them:
- $f''>0$ → minimum.
- $f''<0$ → maximum.
- $f''=0$ → test further (point of inflexion possible).

**Optimisation** — model the quantity to be optimised, differentiate, set $f'=0$, classify.

### ✅ Answer Key

**Q1.**
**(a)** $\dfrac{dy}{dx}=\boxed{12x^{2}-14x+5}$.
**(b)** $y=x^{-2}\Rightarrow\dfrac{dy}{dx}=-2x^{-3}=\boxed{-\dfrac{2}{x^{3}}}$.
**(c)** $y=3x^{1/2}\Rightarrow\dfrac{dy}{dx}=\dfrac{3}{2}x^{-1/2}=\boxed{\dfrac{3}{2\sqrt{x}}}$.

---

**Q2.** $y=\dfrac{x^{3}-2x}{x}=x^{2}-2$. So $\dfrac{dy}{dx}=\boxed{2x}$.

---

**Q3.** $\dfrac{dy}{dx}=3x^{2}-6x$. At $x=2$: $3(4)-6(2)=12-12=\boxed{0}$.

---

**Q4.**
**(a)** $\dfrac{dy}{dx}=2x-4$. At $x=3$: $2(3)-4=\boxed{2}$.
**(b)** Tangent: $y-(-2)=2(x-3)\Rightarrow y=2x-8$. So $\boxed{y=2x-8}$.

---

**Q5.**
**(a)** $\dfrac{dy}{dx}=\boxed{4x-12}$.
**(b)** Set $=0$: $x=3$. $y=2(9)-12(3)+11=18-36+11=-7$. SP $=\boxed{(3,-7)}$.
**(c)** $\dfrac{d^{2}y}{dx^{2}}=4>0$, so $\boxed{\text{minimum}}$.

---

**Q6.** $\dfrac{dy}{dx}=3x^{2}-6x-9=3(x^{2}-2x-3)=3(x-3)(x+1)=0\Rightarrow x=3,\;-1$.

At $x=3$: $y=27-27-27+5=-22$. $\dfrac{d^{2}y}{dx^{2}}=6x-6=12>0$ → minimum.
At $x=-1$: $y=-1-3+9+5=10$. $\dfrac{d^{2}y}{dx^{2}}=-12<0$ → maximum.

$$\boxed{(3,-22)\;\text{minimum};\;\;(-1,10)\;\text{maximum}}$$

---

**Q7.**
**(a)** $\dfrac{dy}{dx}=2x-2$. At $x=3$: $4$. So tangent gradient $=4$.
**(b)** Normal gradient $=-\dfrac{1}{4}$. Equation: $y-3=-\dfrac{1}{4}(x-3)\Rightarrow\boxed{4y+x=15}$ (or $y=-\tfrac{x}{4}+\tfrac{15}{4}$).

---

**Q8.**
**(a)** $v=\dfrac{ds}{dt}=\boxed{3t^{2}-12t+9}$.
**(b)** $v=0\Rightarrow t^{2}-4t+3=0\Rightarrow(t-1)(t-3)=0\Rightarrow\boxed{t=1\text{ s and }t=3\text{ s}}$.
**(c)** $a=\dfrac{dv}{dt}=6t-12$. At $t=1$: $a=\boxed{-6\,\text{m/s}^{2}}$.

---

**Q9.**
**(a)** $2(\text{length}+x)=40\Rightarrow$ other side $=20-x$. So $A=x(20-x)$. ✓
**(b)** $\dfrac{dA}{dx}=20-2x$. Set $=0\Rightarrow x=10$. $\dfrac{d^{2}A}{dx^{2}}=-2<0$ → maximum.

$$\boxed{x=10\,\text{cm}\;(\text{a square, area }100\,\text{cm}^{2})}$$

---

**Q10.**
**(a)** Base $=(20-2x)\times(20-2x)$, height $=x$. So $V=x(20-2x)^{2}$ ✓.

**(b)** Expand: $V=x(400-80x+4x^{2})=4x^{3}-80x^{2}+400x$.

$$\dfrac{dV}{dx}=12x^{2}-160x+400$$

Setting $=0$: $\boxed{12x^{2}-160x+400=0}$ ✓.

**(c)** Divide by $4$: $3x^{2}-40x+100=0$.

$$x=\dfrac{40\pm\sqrt{1600-1200}}{6}=\dfrac{40\pm 20}{6}\Rightarrow x=10\text{ or }x=\dfrac{10}{3}$$

$x=10$ would make the base side zero — invalid. So $x=\dfrac{10}{3}\approx 3.33$ cm.

$V_{\max}=\dfrac{10}{3}\left(20-\dfrac{20}{3}\right)^{2}=\dfrac{10}{3}\cdot\left(\dfrac{40}{3}\right)^{2}=\dfrac{10\cdot 1600}{27}=\dfrac{16000}{27}\approx\boxed{593\,\text{cm}^{3}}$ (3 s.f.).
